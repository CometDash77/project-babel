# M08 · 翻译工程（AiNiee 深度分析）选型调研

调研日期：2026-09-25。**本稿只提供候选、证据和待验门槛，不定主选/备选。**目标是把英文播客逐句转成可追溯的「忠实语义译文」与「最终中文表演稿」，供后续 TTS 使用。先复用 [M08 模块稿](../research/08-translation-engineering.md)与[成熟一条龙项目反查](00-mature-pipeline-stack.md)；下列仓库数据、发布和用户反馈再以公开页面核对。本次未安装工具、调用翻译模型或制作播客样片。

## 证据判读与验收边界

地图要求先看真实运行案例、社区讨论和教程，再看热度、维护与许可，最后综合取舍；仓库 star 或成品演示均不等于本项目的翻译质量。[地图准绳](https://github.com/CometDash77/project-babel/issues/32)、[M08 模块稿的需求及源码分析](../research/08-translation-engineering.md)。本项目必须保留稳定句 ID、原文和两层中文稿、speaker、前后话轮、术语版本、绝对时间、停顿/重叠及修改来源；表演稿还须在 TTS 前核对语义与朗读时长。这些是本项目的验收要求，并非下列候选已具备的功能。[M08 模块稿](../research/08-translation-engineering.md)、[M07 上下文稿](../research/07-smart-context.md)、[M09 质检稿](../research/09-pre-tts-checks.md)。

公开的「跑成功」证据分三层：官方可运行入口/演示，第三方使用或问题反馈，以及本项目同条件验证。前两层存在；**未找到公开可核验的英文两小时多人播客、保留插话与双层中文稿并有人工质量标注的完整案例**。因此任何候选在该目标上的质量、吞吐、费用及故障恢复都**需要实验确定**。[一条龙项目反查的案例边界](00-mature-pipeline-stack.md)、[AiNiee 用户关于缺少下文的实例](https://github.com/NEKOparapa/AiNiee/issues/1086)、[SoniTranslate 长视频用户问题](https://github.com/R3gm/SoniTranslate/issues/184)。

## AiNiee 的可复用边界

- **输入与续跑**：SRT/VTT reader 与 [`CacheProject`/`CacheManager`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/Cache/CacheManager.py)可供字幕导入、行级状态及断点续跑试验；字幕 cue 不等于 M04 稳定句 ID，cue 时间字符串不包含词时戳或重叠双轨。[SRT reader](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Domain/FileReader/SrtReader.py)、[M08 模块稿](../research/08-translation-engineering.md)。
- **词表与人物**：[`PromptBuilder`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Domain/PromptBuilder/PromptBuilder.py)、[`GlossaryHelper`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Domain/PromptBuilder/GlossaryHelper.py)、[`CharacterHelper`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Domain/PromptBuilder/CharacterHelper.py)支持按文本注入术语、角色和背景；[`AnalysisTask`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/TaskExecutor/AnalysisTask.py)可提取候选。播客主持人/嘉宾身份、禁译和别名须人工确认、版本化，不能把模型提取直接当事实。[M08 模块稿](../research/08-translation-engineering.md)。
- **两段生成**：[`TranslatorTask`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/TaskExecutor/TranslatorTask.py)与[`PolisherTask`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/TaskExecutor/PolisherTask.py)可借鉴分阶段处理，但原版润色覆写单一 `translated_text`。应分别保存忠实稿与表演稿，以及每层修订来源。[原版 CacheItem](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/Cache/CacheItem.py)、[Next 双字段](https://github.com/ShadowLoveElysia/AiNiee-Next/blob/7f001a02e2a1655c205534f4eb4537c2027ad123/ModuleFolders/Infrastructure/Cache/CacheItem.py)。
- **自动检查**：[`ResponseChecker`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Domain/ResponseChecker/ResponseChecker.py)、[`TerminologyChecker`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/TranslationChecker/TerminologyChecker.py)、[`RuleChecker`](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/TranslationChecker/RuleChecker.py)能筛行数、空值、术语等规则问题；它们不能证明语义等价、speaker 归属、表演自然度或时长适配。后两者需人工评价与 M09 关口。[M08 模块稿](../research/08-translation-engineering.md)。

## 进入拍板前的启动门槛（均需要实验确定）

1. **同样本与盲评**：取获准个人使用的英文播客，覆盖长节目、两人以上、指代、专名、数字、笑声、打断与重叠。用同一模型/参数比较孤句、AiNiee 前文、M07 前后文及 speaker/事件提示，人工盲评语义、跨句连贯、语气、误添漏译。[AiNiee 下文案例](https://github.com/NEKOparapa/AiNiee/issues/1086)、[M07 稿](../research/07-smart-context.md)。
2. **双层稿与时长**：在相同句子比较原版翻译+润色、Next 双字段流程和 VideoLingo 三步策略；两层均保存原文、ID、模型/提示词/术语版本及人工修订。表演稿须核对原义、可说性、预计 TTS 时长与超预算句，不能仅凭字幕单行长度判过。[原版 CacheItem](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Service/Cache/CacheItem.py)、[Next CacheItem](https://github.com/ShadowLoveElysia/AiNiee-Next/blob/7f001a02e2a1655c205534f4eb4537c2027ad123/ModuleFolders/Infrastructure/Cache/CacheItem.py)、[VideoLingo 流程](https://github.com/Huanshere/VideoLingo/blob/main/docs/pages/docs/introduction.zh-CN.md)。
3. **导入、词表与恢复**：对 M04 句/词时间轴和 SRT/VTT 做往返，逐 ID 核对 speaker、重叠和绝对时间；检查术语别名、禁译、数字与人工豁免；在 Windows/Linux 测试安装、限流、停止/重启、连续两小时恢复、成本与重跑差异。[AiNiee reader](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/ModuleFolders/Domain/FileReader/SrtReader.py)、[任务停止反馈](https://github.com/NEKOparapa/AiNiee/issues/1099)、[M04 稿](../research/04-asr-timeline.md)。
4. **使用条件**：当前限个人用途；若复制、修改、分发或提供网络服务，逐项核对所用版本许可证及模型/API 条款。此项是使用方式门槛，不由仓库 star 或 README 示例替代。[AiNiee 许可](https://github.com/NEKOparapa/AiNiee/blob/295d2ff19cd5ea8ce280a405fe4389a0eec411d7/LICENSE)、[Next 许可](https://github.com/ShadowLoveElysia/AiNiee-Next/blob/main/LICENSE)、[SoniTranslate 模型许可提示](https://github.com/R3gm/SoniTranslate#license)。

**交给 M08 grilling 票的判断题**：翻译工程主体是否从 AiNiee 原版或 Next 改造，还是以 VideoLingo 三步策略作自有任务编排；两层稿分别存储、M07 上下文与 M09 时长关口的成本是否可接受。证据目前只支持候选进入对照，主选/备选由[对应拍板票](https://github.com/CometDash77/project-babel/issues/49)与用户逐题决定。
