# M02 · 人声与背景音分离：选型调研证据稿

调研日期：2026-09-25。**本稿只整理候选和证据，不指定主选、备选或最终模型权重**；这些决定留给「M02 · 人声与背景音分离选型拍板（grilling）」。目标是从英文多人播客提取便于后续分析的人声，同时保留可供中文重演混音的原背景。用户当前仅个人使用；代码、预训练权重和原节目素材的条件仍需分别核对。未在本项目运行模型、试听样片或处理两小时节目，下文的效果和资源判断均不能视作实测。

## 证据基底与成功案例的边界

- [原 M02 模块稿](../research/02-vocal-separation.md)已核对 PodcastMix、audio-separator、Demucs、UVR、粗分段器及其局限；本稿复用其源码检查结果，并补查 2025–2026 的公开状态。[PodcastMix 论文](https://www.isca-archive.org/interspeech_2022/schmidt22_interspeech.pdf)与[真实播客参考轨评测入口](https://github.com/MTG/Podcastmix#evaluate-over-real-podcasts-with-reference)是最直接的同域成功证据，但证明的是研究基线可在部分播客上评测，不证明完整中文重演链路或两小时稳定性。
- [pyVideoTrans 架构](https://github.com/jianchang512/pyvideotrans/blob/main/docs/architecture.md)有可选 UVR/Spleeter 和背景合成；[VideoLingo 技术说明](https://docs.videolingo.io/en-US/docs/tech)有可选 `htdemucs` 分离、ASR 输入和背景轨合成。这是成品流程中「可选分离→背景重混」可运行的公开案例；[前置反查稿](00-mature-pipeline-stack.md)说明两者均未证明多人播客旧人声残留、room tone 与逐段无缝回贴已达标。SoniTranslate [README](https://github.com/R3gm/SoniTranslate)提及分离/增强，未给可核的 stem 时间坐标与重混质量，因此不作为模型优劣证据。
- 面向播客的「成功」与面向歌曲的 vocal/instrumental 演示不能互换。尚未找到公开可核的「两小时英文多人播客→保留音乐/音效/环境声→中文重演重混」案例；本项目上的质量与运行成本**需要实验确定**。[原 M02 模块稿](../research/02-vocal-separation.md)、[前置反查稿](00-mature-pipeline-stack.md)。

## 背景可重混与局部分离的决策输入

1. **输出双 stem ≠ 可安全替换原人声。** [audio-separator 参数](https://github.com/nomadkaraoke/python-audio-separator#full-command-line-interface-options)含归一化、放大、单 stem、反相与输出采样率；[PodcastMix 源码](https://github.com/MTG/PodcastMix-inference/blob/main/forward_podcast.py)还对输出作缩放。两条估计 stem 的波形和原混音未必闭合；用同一采样网格的 `background = original - estimated_voice` 可强制算术闭合，却仍可能留下旧人声或损伤音乐/room tone。这是信号处理推论，不是任何项目已通过的听感结论。保留原 PCM，记录权重、参数、增益、采样率与每段绝对采样偏移；背景可重混质量**需要实验确定**。
2. **粗分段可复用，重叠检测仍未现成闭环。** [inaSpeechSegmenter](https://github.com/ina-foss/inaSpeechSegmenter) 的 speech/music/noise 区间和 CSV/TextGrid 可 **DIRECT REUSE** 做粗窗，且有法国广播电视使用案例；但官方将 speech-over-music 也标为 speech，不能据此检测双源重叠。[YAMNet](https://github.com/tensorflow/models/tree/master/research/audioset/yamnet) 的逐帧事件分数可 **REFERENCE** 为候选窗。两者都不提供「检测 speech+music→仅局部分离→样本对齐回贴」完整流水线；该编排、阈值与接缝**需要实验确定**。多人同时说话属 M03 的局部分离问题，不能把 M02 的人声/背景二分当说话人分离。[M03 模块稿](../research/03-diarization-overlap.md)。
3. **纸上门槛清单。** 后续开工前须用同一批获准个人使用的播客样本盲比纯语音、纯音乐、speech+music、片头尾、音效、笑声、room tone、多人同说和跨麦串音；分别评 ASR/说话人可分析性、背景旧人声残留、音乐/声场损伤、两 stem 回加误差与接缝。再用短段和两小时节目测 Windows/Linux 下显存、内存、耗时、批处理失败恢复，并逐个核对 checkpoint 使用条款。以上指标、门限及候选排序全部**需要实验确定**，本票不执行 GPU 实验。[M02 模块稿实验清单](../research/02-vocal-separation.md)、[TUSS 长音频限制](https://github.com/merlresearch/unified-source-separation#separate-a-sample-with-a-pre-trained-model)。

供 grilling 票逐题确认的焦点：优先保证同域 speech/music 分离证据还是工程封装与维护；背景是否须保留音效/room tone 原貌；旧人声残留的可接受程度；对授权不明的研究权重是否仅保留为对照。上述问题均未在本票拍板。
