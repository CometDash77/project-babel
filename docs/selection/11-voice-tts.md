# M11 · 声音克隆与中文 TTS 选型调研（research）

调研日期：2026-09-25。目标是英文多人播客的中文重演，按音色相似、中文可懂度、原句表演、跨句及多人稳定性分别判断。本稿仅收集候选与证据，**不指定主选或备选**；该决定留给 [M11 拍板票](https://github.com/CometDash77/project-babel/issues/55)。当前用途是个人使用。未下载权重、运行推理或听评同批样本，因此所有效果判断均**需要实验确定**。

证据起点是 [M11 模块稿](../research/11-voice-clone-tts.md) 与 [一条龙项目反查](00-mature-pipeline-stack.md)。下表的“可运行案例”区分官方示例、第三方集成与用户反馈；任何一种都不能证明“两小时英文多人播客→中文同声线成品”已跑通。

## 给拍板票的可核问题

1. 用同一批已获授权的英文多人播客片段做盲评：固定 speaker 参考、逐句原声参考、固定音色加独立情绪参考或指令（仅在对应接口可用时）各跑一组。分开记录中文可懂度、同人音色、表演方向、跨句漂移和多人混淆；**需要实验确定**。[Breeze 接口](https://github.com/breezeblue-ai/breeze-tts/blob/main/README.md)、[Index API](https://github.com/index-tts/index-tts/blob/main/README.md#-python-api)、[Qwen Base 入口](https://github.com/QwenLM/Qwen3-TTS#voice-clone)。
2. 将干净、准确转写的英文参考与带音乐、笑声、重叠、极短句的参考分层；核对跨语言口音和原句表演。逐句更换参考是否优于固定参考**需要实验确定**。[pyVideoTrans 克隆 FAQ](https://github.com/jianchang512/pyvideotrans/blob/main/docs/faq.md)、[GPT-SoVITS 跨语言口音反馈](https://github.com/RVC-Boss/GPT-SoVITS/issues/1054)。
3. 按拟部署设备测各确切版本的安装、显存峰值、首句延迟、逐句失败/重试及多 speaker 切换；两小时落盘与恢复交给 M12 共同验证，**需要实验确定**。[M12 模块稿](../research/12-long-audio-assembly.md)。
4. 保存每个具体权重、附属模型和参考音频的授权记录。当前仅个人用途；若日后发布、收费或提供服务，重新核对许可。Index 的自定义许可、Breeze/F5 权重的非商业限制以及 GPT-SoVITS 多组件许可尤其需逐项核对。[Index 许可](https://github.com/index-tts/index-tts/blob/main/LICENSE)、[Breeze 权重卡](https://huggingface.co/BreezeBlue/Breeze-TTS-2)、[F5 许可说明](https://github.com/SWivid/F5-TTS#license)、[GPT-SoVITS 权重目录](https://huggingface.co/lj1995/GPT-SoVITS)。

**调研边界：**现有公开演示与集成足以组成可试候选池，但未找到可核的两小时英文多人播客中文重演样本，也未同设备、同参考音和同译文比较。主选、备选、评分阈值与资源预算均留待 [M11 拍板票](https://github.com/CometDash77/project-babel/issues/55)；实际效果**需要实验确定**。
