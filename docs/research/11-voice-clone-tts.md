# M11 · 声音克隆与中文 TTS

调研日期：2026-09-25。目标是把英文多人播客重演成可懂的中文，同时尽量保留各说话人的音色、语气、节奏和互动。本稿只核对官方仓库、模型卡、接口与许可证；**未下载权重、训练、推理或生成样片，也没有同批样本听评**。厂商演示和论文分数只能证明值得试，不能证明本项目效果。当前用途按用户说明为**个人使用**；如以后传播、收费或提供服务，需重新核对输入声音授权及每项权重、输出、依赖许可。

## 结论与判断口径

**先并行试 Breeze TTS 2、IndexTTS-2.5、Qwen3-TTS Base、CosyVoice 3，再让 GPT-SoVITS 作为成熟工程基线；F5-TTS 作为可复现的低控制基线。**这不是音质排名。Breeze 的参考引导和文字 voice direction 与需求最贴近，但官方只列英语/中文、Linux/CUDA 和 12 GB 最低推荐；IndexTTS-2.5 的音色/情绪解耦及语速、拼音控制适合检验逐句表演；Qwen Base 的批量及可缓存 speaker prompt 很适合检验多人稳定性，但 **Base 克隆入口没有文档所示的 `instruct` 参数**，不能把另一个 VoiceDesign/CustomVoice 权重的指令能力算作“克隆且可导演”；CosyVoice 3 的跨语言克隆、指令及服务封装较完整。上述判断分别来自[官方 Breeze 接口](https://github.com/breezeblue-ai/breeze-tts#-quick-start)、[IndexTTS README](https://github.com/index-tts/index-tts#-python-api)、[Qwen 模型矩阵及克隆入口](https://github.com/QwenLM/Qwen3-TTS#released-models-description-and-download)、[CosyVoice README/示例](https://github.com/QwenAudio/CosyVoice/blob/main/example.py)；声音质量与长播客一致性**需要实验确定**。

四个判断必须分开：①**能克隆音色**＝接口接受参考声音，绝非已验证像本人；②**能说中文**＝官方列中文输出，绝非中文可懂度过关；③**能控制表演**＝有参考、情绪、速度或指令入口，绝非能准确重演原句的情绪/停顿；④**适合长播客**＝能按句调度、多人复用和落盘恢复，绝非单次生成两小时。后者还取决于 M12 的 timeline/拼接与断点续跑。本次没有候选在相同英文→中文播客样本上同时通过这四项。

`DIRECT REUSE` 指可直接调用明确的模型/API；`WRAP·ADAPT` 指轮子可用但须做逐句参考选择、质量检查或编排；`REFERENCE` 只借鉴或作对照；`REJECT` 指在本票的**原声克隆路径**不适用，不代表项目整体无价值。任何分类均不是生产验收。

## 关键问题：每句使用对应原始 reference segment

六种候选的推理入口都可以**在句与句之间传不同参考文件**（Qwen 还可把每个 speaker 的 prompt 缓存），所以工程上无须整期固定一段。这只解决“可传入”的问题，不解决“能继承”。英文原句里音高/节奏与中文字数、声调、停顿不一一对应；参考可能混入音乐、笑声、重叠者或过短发声。逐句更换 reference 还可能令同一人声线、口音和响度跳变。Index 的独立情绪参考尤其值得试，但其 `emo_audio_prompt` 是否比“换整段音色参考”稳，仍**需要实验确定**。所有候选均不得把一人一句的参考给另一人；应保存 `speaker_id`、原音频片段时间、参考转写、质量标签和使用的模型版本，以便复现与剔除失败句。

## 后续同批样本实验清单（本票未执行）

1. 取已获使用授权的同一批英文播客：至少 3 位声线、男女及口音差异、平静/愤怒/轻声/笑前后、打断/重叠、音乐底、短句与较长句。每段保存真实 speaker、时间、干净参考 WAV、准确英文转写及同一份中文表演稿；重叠与非语音事件单独标记。不得以各项目自带 demo 互比。
2. 固定模型版本、设备、随机种子、文本正规化、目标音量，分别跑 **固定 speaker 参考**、**逐句对应英文原句参考**、**固定音色＋逐句情绪/指令**（仅支持的模型）、**错情绪参考负对照**。每句记录参考时长/质量、推理设置和输出文件；Qwen Base 的指令项记“不支持此入口”，不强行补造。
3. 盲评中文母语听众的**可懂度**（人名、数字、术语、声调、漏字/添字）、**音色相似度**（与同一英文 speaker 多片段对照）、**表演匹配**（情绪方向、重音、停顿、速度、笑/叹气处）、**多人一致性**（跨句声线漂移、speaker 混淆、轮次切换）。分开打分，保留原句、中文稿与音频成对比较；记录评委间分歧。ASR/CER、speaker embedding 只作辅证，不替代听评。
4. 对短句、英文参考→中文目标、噪声/音乐、同一人极端语气、换参考边界做分层统计；记录哪一类“有音色却没语气”“中文可懂却不像本人”“表演夸张而音色漂移”。比较生成时长与原句时长，**不预设**速度参数就能精确贴合时间轴；时长和内容约束与 M09/M12 接续。
5. 在可丢弃环境分别测 Windows/Linux 的安装与一次推理，GPU 峰值、内存、首句延迟、每小时成品耗时、批量失败率；再测按句落盘、重试、重启后继续、多 speaker 轮换及两小时素材总量。这里的 checkpoint/resume 归 M12 编排层，本票只向其交付 TTS 单句接口和失败记录要求。
6. 每个拟用的**确切权重**逐一保存模型卡/许可版本及附属模型清单；个人用途也核对参考音频使用权。尤其复核 GPT-SoVITS 的预训练组件许可、Index 自定义许可、Breeze/F5 的非商业限制，以及未来是否发布或商业化。

当前可确认的是官方功能入口与许可文本，**不是**同一批样本上的音色、中文可懂度、表演控制或长播客验收。生产主模型、每句参考选择规则、评分阈值及显存预算均**需要实验确定**。
